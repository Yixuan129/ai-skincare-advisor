# 数据与素材

## 数据最小化

本仓库没有包含问卷答卷、访谈原文、逐条评论或平台评论 ID。研究说明只保留汇总数量、方法、限制与产品决策。

## 产品数据

`data/products.json` 为项目已有产品资料的结构化提取，覆盖 11 个本地产品编号。价格为资料 RSP，不是实时售价；功效、用法及适用人群字段未全部完成公开来源核验。保留提取状态和待核验字段，便于理解原型的资料边界。

## 第三方素材

`public/product-images/` 包装图片来自项目产品材料，来源映射见 `data/product-image-sources.json`。品牌、商标、产品图片及资料版权归各自权利人。项目文件没有证明它们获准以开源许可再分发；本仓库不对它们授予许可。

首页背景、面部示意图和页面截图仅用于展示现有原型。本次整理没有独立核验每项素材的授权链。因此建议仓库先保持私有，在公开之前核对素材许可，必要时替换图片和产品原文。

没有为本项目添加 MIT 等开源许可证，以免将不属于项目作者的素材一并授权。
